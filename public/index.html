🏆 Direktori Speedrun Medali GitHub

🤠

Quickdraw

30 Detik • 100% Solo

Menutup issue atau pull request dalam waktu kurang dari 5 menit setelah dibuat.

  • Buat issue baru di repo publik apa saja.
  • Beri judul bebas (contoh: test quickdraw).
  • Segera klik tombol "Close issue" dalam hitungan detik.
🦈

Pull Shark

2 Menit • 100% Solo

Membuka dan menggabungkan (merge) Pull Request ke branch utama.

  • Bronze: Cukup merge 2 Pull Request.
  • Silver (x2): Capai 16 Pull Request merged.
  • Gold (x3): Capai 128 Pull Request merged.
🧠

Galaxy Brain

5 Menit • Kolaborasi

Mendapatkan jawaban yang diterima (marked as answer) di GitHub Discussions.

  • Aktifkan fitur Discussions di Settings repositori.
  • Minta akun kawan membuat diskusi kategori Q&A.
  • Jawab diskusi tersebut, lalu tandai sebagai "Mark as answer" (butuh 2x untuk Bronze).
🤝

Pair Extraordinaire

3 Menit • Co-Author

Melakukan merge pull request yang memiliki trailer Co-authored-by:.

  • Gunakan generator commit di bagian atas halaman ini.
  • Pastikan format email co-author sesuai akun GitHub aktif.
  • Merge branch tersebut ke default branch (main).
🚀

YOLO

1 Menit • Tanpa Review

Melakukan merge pull request tanpa menunggu review atau persetujuan reviewer.

  • Saat membuat PR, request review ke rekan kolaborator.
  • Tanpa menunggu teman melakukan approval, langsung klik Merge pull request.
💖

Public Sponsor

Resmi • $1 Donasi

Mendukung pengembang open-source melalui platform resmi GitHub Sponsors.

  • Pilih developer open-source dengan tier $1 (misal: pengembang library Flutter/tema).
  • Pilih opsi visibilitas Public Sponsor (jangan anonymous).
  • Lencana hati pink akan menempel permanen di profil.
